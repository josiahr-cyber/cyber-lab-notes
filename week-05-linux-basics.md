## What I learned
- I learned that Linux is an operating system that is very common in cybersecurity, and a lot of it is controlled from the command line.

## Commands I practiced
- `ls`: lists the files and folders where I am
- `cd`: changes the folder I'm working in
- `cat`: prints what's inside a file on the screen
- `grep`: searches for text inside a file and shows the lines that match

## What was hard
Remembering the more complex commands like grep. I'll practice it on a text file to make it stick.
